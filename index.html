Aviso: no Android, apps web não conseguem ouvir com a tela desligada como o "Ok Google". A escuta funciona com o app aberto. Gmail, Agenda e Drive usam o botão Conectar Google.

Conectores: Gmail, Agenda, Drive (backup), Canva (Client ID no Worker). Câmera/arquivos: botão anexar.

Canva: configure CANVA_CLIENT_ID e CANVA_CLIENT_SECRET no Worker (Outside Canva → REST API).

Crie um app em canva.com/developers → Authentication → Redirect URI: a URL deste site (ex. https://lucas15mpaula-blip.github.io/F.O.X.I.A/). Cole o Client ID acima. Scopes: design:content:write, design:meta:read.
